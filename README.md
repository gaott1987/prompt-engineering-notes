# Prompt Engineering Notes

A collection of prompt engineering methodologies, experiments, and case studies from hands-on LLM usage.

## Why This Repo

This repo started as a personal effort to organize my own prompt engineering practice — patterns I use, what works, and why. Over time, it has grown into a structured set of notes that can also serve as a reference for building more systematic, engineering-oriented prompting workflows.

It focuses on:
- **Methodology**: repeatable patterns, not one-off tricks
- **Experiments**: side-by-side comparisons with observed results
- **Case studies**: real problems I encountered and how I approached them

## Structure

- `methodology/` — patterns I use regularly, with rationale
- `experiments/` — controlled comparisons of prompting strategies
- `case-studies/` — deep dives into specific problems

## Background

This repo is maintained by someone who uses LLMs daily — for prototyping, problem-solving, and exploring how to make model outputs more reliable. The methodologies here are general-purpose and not tied to any specific domain; the examples and case studies illustrate how they are applied in specific contexts, including AI application development.
